# Auto Settings change log

## v1.1.5 · 2026-10-21 · 4f919c6

Edit the settings display on the preview itself, version 1.1.0

- Auto AHU style layout: compact header with a File menu and Copy to atvise, one canvas card, the version in the corner
- Settings are added with + markers between rows as a combobox; click a label to rename it, click the control to change its type or remove it, drag a row to reorder it, hover and press Delete to remove
- Click the title to rename it; title buttons are added with + markers beside the title and edited by clicking them
- Settings boxes are resized by dragging their sides
- Full display can hold several settings sections, added below or on either side as columns and removed with the x on each section
- Build mode switch on the canvas; sizes, fonts and colours moved to File > Settings
- Save a display as a named default and load it back from the File menu
- Export writes every section, the first keeps its existing ids
- Version 1.1.0; the patch number now counts commits since the last version change
